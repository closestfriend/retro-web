# retro-web (Artifacts of Self-Authorship)

Eleven self-contained static HTML documents reconstructing personal homepages from the 1998–1999 web, accompanied by an essay on constructed online identity (`statement.md`).

## Index of Pages

- `index.html` — Webring directory and collection index
- `dark-poetry.html` — Late-90s gothic poetry & guestbook page
- `hackz0r.html` — Phreaking/handle culture portal
- `y2k-survival.html` — Off-grid Y2K preparedness bulletin
- `geocities.html` — Anime shrine & MIDI/marquee homestead
- `photographer.html` — Amateur film photography gallery
- `academic.html` — University faculty hypertext syllabus
- `seeker.html` — Millenarian contactee transmission log
- `nu-metal.html` — Regional band fan page & tour diary
- `government.html` — Archival federal bureau index
- `brotherhood.html` — Initiatic society recruitment page
- `netart.html` — Browser-native net.art documentation piece

## Markup Constraints

All eleven documents use period-accurate static HTML/CSS (nested table layouts, `<font>` tags, `<marquee>`, inline hex palettes, and keyframe-emulated `<blink>`) with no external dependencies or build steps. Open `index.html` in any browser.
